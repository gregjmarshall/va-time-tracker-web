# Capacity

**Capacity** shows, for each person and month, the hours **allocated** to each client against the hours **used**.

## Read the page

- Totals across the top: **Allocated**, **Used**, **Remaining** (or *over*) and **Holiday cover**.
- One row per person, which you can expand to see each client.
- **Used** is the time they logged that month on their own clients.
- **Holiday cover** is shown separately and doesn't use up their allocation.

Team members see their own month on **Overview**, under *<Month> hours*.

## Set allocations

1. Press **Edit** on a person (or **allocate hours** if they have none).
2. Set monthly hours per client, or **+ Add a client…**
3. Set a client to **0** to remove it.

Allocations apply from the selected month **onwards**. Earlier months keep their hours.
