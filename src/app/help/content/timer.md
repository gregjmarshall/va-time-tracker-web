# The timer bar

The timer bar sits at the top of every page. It has a description box, a project picker, the elapsed time and the controls.

## Start, pause and stop

1. Type what you're working on (optional, unless your workspace requires a description).
2. Pick a project. You can also do this later.
3. Press **▶ Start**.

While it's running:

- **Pause (❚❚):** stops the clock but keeps the session open. The time shows **Paused** in yellow. Press ▶ to resume, and the session keeps adding up.
- **Stop (■):** saves the time as an entry. If you haven't picked a project, pip asks *Which project is this for?* Click away to keep the timer running.
- **Discard (bin):** throws the whole session away. This can't be undone.

You can change the description or project while the timer runs. When you stop, every paused part of the session is saved with the final project and description.

## Things to know

- You can only run **one timer at a time**.
- A running or paused timer follows you across pages and devices. It's saved on the server, not just in your browser.
- To start quickly, use **Start** on a project card in [My projects](/help/my-projects).
- If your workspace **requires descriptions**, Stop won't save until you add one.
- If the week is **submitted or approved** on your [timesheet](/help/timesheets), the timer can't start, because that week's time is locked.

## Fixing a mistake

Saved entries are listed under **Recent entries** on Overview. Use the **⋯** menu on an entry to **Edit** it (description, project, start and end) or **Delete** it.
