# My projects

**Projects** in the sidebar shows team members every project they can track time to.

## Each card shows

- The project and its client. The coloured edge is the client's colour.
- **This month** and **All time:** your own hours, not the whole team's.
- **Budget:** if the project has one.
- **Last tracked:** when you last tracked time to it.

## Start a timer from a card

Press **Start** on a card to start the timer on that project, then type what you're doing in the timer bar. A card shows **Running** while its timer runs.

**Start** is greyed out when a timer is already running or paused. Finish or discard that one first.

## A project is missing

You only see projects you're assigned to, plus all projects of clients you've been given visibility of, or are covering. Ask a Manager to change your [access](/help/team#access-and-visibility).
