# Manual entries

Use a manual entry when you forgot to run the timer.

## Add an entry

1. Go to **Overview** and press **+ Manual entry** above Recent entries.
2. Fill in the **description**, the **project**, and the **start** and **end** times.
3. Press **Add entry**.

The start time defaults to an hour ago and the end time to now.

## Edit or delete

On Overview, open the **⋯** menu on an entry in **Recent entries** and choose **Edit entry** or **Delete**.

## Rules

- A project is always required.
- A description is required if an Admin has turned that on in **Settings**.
- The end time must be after the start time.
- Entries in a week that's **submitted or approved** on the timesheet can't be added, changed or deleted. Withdraw the week first, or ask an Admin.
- Managers and Admins see a **Billable** tickbox, but Team members don't (see [Rounding and billable](/help/rounding-and-billable)).

> **Tip:** The [timesheet](/help/timesheets) is often quicker for filling in a whole week.
